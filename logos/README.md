# CLIF Logo

Official logo assets for CLIF.

- `logo-light.svg` — square logo for light backgrounds.
- `logo-dark.svg` — square logo for dark backgrounds.
- `clif-wordmark-light.svg` — wordmark for light backgrounds.
- `clif-wordmark-dark.svg` — wordmark for dark backgrounds.

The wordmark uses Inter Ultra-Bold Italic (SIL OFL, free for commercial use). The visible text is converted to vector outlines so it renders consistently without requiring the font to be installed.
